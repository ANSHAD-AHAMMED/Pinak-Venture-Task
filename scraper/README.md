# IBPS Job Scraper (Python)

A Python web scraping script that automatically extracts the latest recruitment/job notifications from the official IBPS (Institute of Banking Personnel Selection) website.

The script scrapes:

- Job Title
- Publish/Post Date
- Location (if available)
- Direct Link to the Job Notification

The scraped data is saved into a CSV file named **`ibps_jobs.csv`**.

---

## 🚀 Features

✅ Uses `requests`, `BeautifulSoup4`, and `pandas`  
✅ Automatically scrapes current IBPS job notifications  
✅ Handles SSL/network issues gracefully  
✅ Saves extracted data to a CSV file  
✅ Well-commented and production-ready code
